🧠 Project Title

STIX to RDF Converter and Graph Database Integration

📘 Overview

This project converts STIX 2.1 Cyber Threat Intelligence (CTI) data into RDF triples and stores them in a graph database (GraphDB).
It allows querying using SPARQL to analyze relationships between cybersecurity entities such as indicators, malware, and campaigns.

🎯 Objectives

Transform STIX JSON data into RDF triples.

Store and manage CTI data in a semantic graph database.

Execute SPARQL queries for meaningful insights into cyber threats.

Explore relationships using the UCO ontology to ensure interoperability and semantic consistency.

🧩 Technologies Used

Java (with Apache Jena / RDF4J)

Maven (for dependency management)

STIX 2.1 examples from OASIS repository

SPARQL for data querying

UCO ontology for semantic modeling

🔮 Future Work

Integrate real-time CTI feeds using TAXII.

Extend UCO ontology to fully support all STIX components.

Apply Machine Learning for automatic threat pattern detection.
